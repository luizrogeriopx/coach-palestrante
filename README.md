# Coach & Palestrante – Site Institucional

Este repositório contém o site **Coach-Palestrante**, um projeto desenvolvido para promover serviços de coaching, palestras motivacionais e programas de desenvolvimento pessoal.  
Foi construído com **HTML5**, **CSS3** e **JavaScript** de forma simples, moderna e responsiva.

🔗 **Veja o site online:**  
https://luizrogeriopx.github.io/coach-palestrante/

---

## 📖 Sobre o projeto

O site serve como uma **vitrine digital profissional** para um coach ou palestrante, apresentando:

- Introdução e missão
- Serviços de coaching e palestras
- Depoimentos e diferenciais
- Informações de contato

O objetivo é proporcionar uma experiência clara, agradável e acessível ao usuário.

---

## 💻 Tecnologias Utilizadas

Este projeto foi desenvolvido com:

- **HTML5** — Estrutura semântica da página  
- **CSS3** — Estilização visual e layout responsivo  
- **JavaScript** — Interações e efeitos dinâmicos

Não foram usados frameworks externos — todo o código é puro (vanilla) e leve.
